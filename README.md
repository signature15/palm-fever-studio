# Palm Fever Cover Studio

Palm Fever Cover Studio is an offline, GTA-style multi-panel cover studio that turns a photo and a caption into Vice City-flavoured cover art entirely in the browser: it lays your image out as a canvas mosaic of 8 photo panels, re-grades each panel with an ink-comic look, and sets your caption in bold gradient lettering with a heavy outline, ready to export in three sizes. The app is plain static files in `app/` with no libraries and no network requests, so it runs from a local server with nothing else installed.
